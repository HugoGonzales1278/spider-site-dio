## 📖 Sobre o projeto

O **Spider-Site DIO** é uma landing page criada como parte do desafio de projeto **"Landing Page Spider-Man"** proposto pela DIO. O objetivo é praticar HTML, CSS e JavaScript construindo uma página responsiva e interativa em homenagem aos três atores que já viveram o Homem-Aranha nos cinemas: **Tobey Maguire**, **Andrew Garfield** e **Tom Holland**.

Além da landing page principal, o repositório conta com uma versão experimental (`spiderAI.html`) explorando outras abordagens de layout e conteúdo.

## 🚀 Demonstração

Abra o arquivo `index.html` diretamente no navegador para visualizar o projeto localmente, ou publique via **GitHub Pages** para compartilhar o link.

## 🛠️ Tecnologias utilizadas

- **HTML5** — estruturação semântica do conteúdo
- **CSS3** — estilização e responsividade
- **JavaScript** — interatividade da página

## ▶️ Como executar

```bash
# Clone o repositório
git clone https://github.com/HugoGonzales1278/spider-site-dio.git

# Acesse a pasta do projeto
cd spider-site-dio

# Abra o index.html no navegador de sua preferência
```

Não é necessário nenhum servidor ou instalação de dependências — o projeto é 100% front-end estático.

## 🎯 Objetivos do desafio

- Aplicar conceitos de HTML semântico
- Praticar estilização com CSS (flexbox/grid, responsividade)
- Adicionar interatividade com JavaScript
- Organizar um projeto front-end em pastas de forma clara
